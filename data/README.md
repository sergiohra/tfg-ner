# Datos

Los datasets se descargan automáticamente al ejecutar los scripts mediante la librería datasets de HuggingFace.

## Datasets utilizados

- **WikiANN (es)**: load_dataset("wikiann", "es") — 10.000 frases en test, Wikipedia, silver-standard
- **CoNLL-2002 (es)**: load_dataset("conll2002", "es") — 1.518 frases en test, noticias EFE, gold-standard

No es necesario descargar nada manualmente.
